# Campeonato Nacional Sub-18 de Rugby 🏉

Website dinâmico e responsivo para acompanhamento do Campeonato Nacional Sub-18 de Rugby em Portugal.

## 🌟 Funcionalidades

- **1ª Fase:** Campeonato com 11 equipas (11 jornadas, 1 folga por jornada).
- **2ª Fase:** Grupos A e B (para os 8 primeiros classificados).
- **3ª Fase:** Play-offs e Grande Final.
- **Modo Administrador Protegido:**
  - Adicionar/editar resultados dos jogos e datas.
  - Inserir ensaios para atribuição de Ponto Bónus Ofensivo.
  - Edição direta de pontos na tabela.
- **Regras de Pontuação do Rugby Português:**
  - Vitória: 4 pts | Empate: 2 pts | Derrota: 0 pts
  - Bónus Ofensivo (BO): 4 ou mais ensaios (+1 pt)
  - Bónus Defensivo (BD): Derrota por 7 ou menos pontos (+1 pt)

## 🔐 Acesso Admin
- **Palavra-passe predefinida:** `rugby123`

## 🚀 Como Executar

1. Clona o repositório ou faz o download dos ficheiros.
2. Abre o ficheiro `index.html` em qualquer navegador web.
3. Para colocar online gratuitamente, ativa o **GitHub Pages** nas definições deste repositório!
